# Tellsy

**Your screen, out loud. Your voice, typed.**

Tellsy reads anything on your screen aloud and lights up each line as it goes, answers questions about it, and types your spoken replies into any text box. Free for Windows 10 and 11.

**Website and download:** https://lokiencoded.github.io/tellsy-app/

This repository holds the website and the public installers (see [Releases](https://github.com/LokiEncoded/tellsy-app/releases)). Tellsy's source code is private. By installing Tellsy you accept its [terms of use](https://lokiencoded.github.io/tellsy-app/terms.html).
